# Hong Kong road car package

This is the Assetto Corsa source package for the first Hong Kong road car:
an original Crown Comfort-type taxi model intended for right-hand-drive
Kowloon traffic.

The package is deliberately mesh-independent. Add the authored model files to
this directory before installation:

```text
hk_crown_comfort.kn5
data/*.ini
skins/default/
ui/ui_car.json
```

The `data` values are a baseline for a naturally aspirated, four-speed
automatic, rear-wheel-drive road sedan. They must be validated against the
final authored model and reference vehicle before release. Do not distribute
manufacturer logos, ripped meshes, or unlicensed textures.

For a local install, copy this directory to:

```text
content/cars/hk_crown_comfort/
```
